# Mika — Product Designer Portfolio Template

قالب یک‌صفحه‌ای (One-Page) پورتفولیوی طراح محصول، در دو نسخه‌ی کاملاً مستقل:

```
project/
├── en/                     ← نسخه‌ی انگلیسی (LTR)
│   ├── index.html
│   └── assets/
│       ├── css/style.css
│       └── js/main.js
│
├── fa/                     ← نسخه‌ی فارسی (RTL)
│   ├── index.html
│   └── assets/
│       ├── css/style.css
│       └── js/main.js
│
└── README.md
```

هر دو نسخه کاملاً مستقل و قابل میزبانی جداگانه هستند (هیچ فایل مشترکی بین `en/` و `fa/` وجود ندارد).

## اجرا

هیچ ابزار build یا وابستگی‌ای لازم نیست. کافی‌ست فایل `index.html` هر پوشه را در مرورگر باز کنید، یا کل پوشه (`en` یا `fa`) را روی هر هاست استاتیک (GitHub Pages، Netlify، Vercel، cPanel و…) آپلود کنید.

## ساختار کد

- **`index.html`** — فقط مارکاپ صفحه، تقسیم‌شده به بخش‌های کامنت‌گذاری‌شده: ناوبری، هیرو، تیکر، نمونه‌کارها، توانمندی‌ها، فرآیند، نقل‌قول، تماس/فوتر.
- **`assets/css/style.css`** — تمام استایل‌ها با کامنت بخش‌بندی‌شده (توکن‌های طراحی، ریست، لودر، ناوبری، هیرو، ریسپانسیو و…).
- **`assets/js/main.js`** — منطق جاوااسکریپت در بلوک‌های جدا با کامنت: سوییچ تم روشن/تاریک، منوی موبایل، پیش‌بارگذاری، انیمیشن Scroll-Reveal، مکان‌نمای سفارشی.

فونت‌ها از طریق Google Fonts CDN لود می‌شوند (نیازی به دانلود فایل فونت نیست): Fraunces / Inter / IBM Plex Mono برای نسخه‌ی انگلیسی، و Vazirmatn / IBM Plex Mono برای نسخه‌ی فارسی.

## یادداشت فنی

نسخه‌ی انگلیسی در فایل اولیه فاقد دکمه‌ی «منوی موبایل» در مارکاپ بود (در حالی‌که استایل و منطق آن در CSS تعریف شده بود)، به همین دلیل در حالت موبایل امکان باز کردن منو وجود نداشت. این مورد در بازسازی، هم‌راستا با پیاده‌سازی صحیح نسخه‌ی فارسی، اصلاح شد تا هر دو نسخه از نظر عملکرد یکسان و کامل باشند.
